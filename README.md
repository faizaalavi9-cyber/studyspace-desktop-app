# StudySpace — Desktop Study & Productivity App

StudySpace is a desktop application designed to help students organize their academic activities, manage tasks, plan study schedules, track examinations, and maintain focused study sessions.

## Features

- **Dashboard:** Overview of tasks, exams, and study progress.
- **Task Manager:** Add, complete, delete, and filter tasks.
- **Study Planner:** Organize study activities and schedules.
- **Exam Tracker:** Add examinations and monitor countdowns.
- **Focus Timer:** Dedicated study sessions with multiple timer durations.
- **Analytics:** Track task completion and study activity.
- **Local Storage:** Save application data locally.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Electron

## Installation and Setup

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the desktop application:

   ```bash
   npm start
   ```
